# pin16

Открытая прошивка и страница управления для маленьких электронно-бумажных тегов, похожих на значки: **картинки загружаются по Bluetooth LE с веб-страницы и показываются слайд-шоу**, без прошивки по SWD ради каждой картинки. English version: `README.md`.

Поддерживаемые теги (EFR32BG22C224F512IM40, CR2450, NFC, внешняя SPI flash 512 КБ):

| Тег | Панель | Размер | Цвета |
|---|---|---|---|
| Solum EL016F5W4C, EL016F6W4A | EL016 | 200 x 200 | чёрный, белый, жёлтый, красный |
| Solum EL022F5C4C | EL022 | 296 x 160 (развёртка 160 x 296) | чёрный, белый, жёлтый, красный |

Другие теги на той же плате, но с другим контроллером, работают по Bluetooth и сообщают о себе, однако прошивка на них не рисует, пока не добавлена последовательность их панели (`docs/DIAG.ru.md` описывает, как её записать).

## Возможности
- Картинки переводятся в браузере (пресеты, растр, масштаб, поворот), до 32 слотов во внешней flash, хранение raw / LZ4 / XOR+LZ4, превью читаются обратно с тега
- Слайд-шоу по таймеру, периодическая очистка, касание = следующая картинка, стартовая заставка
- Обновление прошивки по Bluetooth (OTA) с проверками; опасные команды — только в течение 60 с после касания тега
- Запись в NFC-чип ссылки, короткого текста или доступа к Wi-Fi (с обратным чтением и проверкой; пароль Wi-Fi прочтёт любой, кто коснётся тега)
- Сигналы светодиода, необязательный маяк BTHome, режимы локатора, защита по батарее и сторожевой таймер
- Необязательная диагностическая сборка: карточка железа (выводы, заводские данные, записанный обмен с панелью и NFC)
- Панель прогресса, закреплённая вверху страницы (проценты, байты, время) для загрузок, обновления прошивки и превью; тестовая картинка ориентации
- Часть протокола OpenDisplay (сервис 0x2446) рядом со своим протоколом; описание для сторонних клиентов в `docs/PROTOCOL.ru.md`
- Страница на английском и русском, работает офлайн как приложение (PWA)

## Репозиторий
- `firmware/` собственный код (слой железа, драйверы панели и NFC, слоты, Bluetooth, OTA, светодиод), `firmware/BG22Badge.slcp` — проект для Silicon Labs Gecko SDK 4.4.1
- `web/` страница управления (`index.html`, `sw.js`, манифест, иконки)
- `tests/host/` тесты модулей на ПК (имитация flash, регистратор панели, виртуальное время, AddressSanitizer)
- `bootloader/` собственный проект загрузчика Gecko для тегов (компоненты из примера SDK, выводы, патч драйвера флеш при сборке); кода SDK внутри нет
- `docs/` руководство, протокол (`PROTOCOL.ru.md`), железо (выводы, панели, NFC), диагностическая сборка
- `Dockerfile`, `build_all.sh`, `.github/workflows/main.yml`: сборка в GitHub Actions; артефакты: `*_FULL_vN.s37` (загрузчик + прошивка одним образом), `ota_files/pin16_vN.ota.bin`, `firmware.s37`, варианты `_diag`

## Установка
* Тег, на котором уже стоит эта прошивка (или более ранняя с загрузчиком): обновление по Bluetooth, карточка страницы «Обновление прошивки», файл `pin16_vN.ota.bin`.
* **Заводской тег**: он закрыт; снятие защиты по SWD навсегда стирает заводскую прошивку (сохранить её нельзя), и после этого загрузчика в теге нет. Запишите образ «всё в одном» `SOLUM_BTL_FULL_vN.s37` (загрузчик + прошивка). Пошагово в `docs/USER_GUIDE.ru.md`, «Первая установка на заводской тег».
* Тег, где загрузчик уже есть (прежний проект, снятая защита): запишите `firmware.s37` с адреса 0x6000 по SWD или обновите по Bluetooth.
