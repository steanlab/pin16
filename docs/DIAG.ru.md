# Диагностическая сборка («карточка железа»)

English version: `DIAG.md`.

Workflow собирает две прошивки: обычную и с `-DBG_DIAG` (файлы `*_diag*`, `pin16_vN_diag.ota.bin`).
В диагностической добавлен `firmware/hwcard.c`: журнал всего, что идёт по шине панели и по шине NFC после включения, и карточка с тем, что тег знает о себе. В обычной сборке кода журнала и памяти под него нет (`hwcard.h` превращает вызовы в пустые операторы).

## Как снять карточку с нового тега
1. Прошейте или установите образ `_diag` (OTA тоже работает: сначала приложите телефон к тегу). Панель нарисует стартовую заставку, журнал запишет эту отрисовку.
2. Подключитесь страницей, прокрутите страницу вниз, откройте «Дополнительно», затем «Для разработчиков» и нажмите **Hardware card (diag build)** (v20; `4F 0F`) или **ID / reset** (`4F 0D`). Тег выдаст карточку и журнал текстовыми строками. На странице — «Копировать журнал».
3. `4F 0F 00` очищает журнал: следующая отрисовка (например, тестовая картинка) будет записана.
4. Пришлите журнал (все строки: `HW`, `PANEL`, строки выводов, `NFCCHIP`, `NFCAI`, `NFCTEXT`, `GPIN`, `UD`, `FLASH`, `SFDP` и `TR`) и фото платы с двух сторон.

## Строки карточки
- `HW tag=.. ctrl=.. col=.. res=WxH capa=..`: заводская страница; `PANEL EL016/EL022/? ok=.. WxH mirror=..`: что выбрала прошивка
- строки выводов `SCK= MOSI= CS= DC= RST=`, `BUSY= EN=`, `FLASH`, `NFC`, `IO` (кнопки, светодиод), `DBG`; `GPIN`: уровни всех выводов портов A..D сейчас
- `NFCCHIP present= reg25= ln=`, `NFCAI` (блок атрибутов), `NFCTEXT kind= cap= text` (что хранит чип: kind 1 ссылка, 2 текст, 3 имя сети Wi-Fi)
- `UD 00:` .. `UD 70:`: первые 128 байт заводской страницы
- `FLASH JEDEC aa bb cc` и `SFDP 00:`, `SFDP 10:` и ещё четыре строки `SFDP xx:` (v20; v19 печатала первые 128 байт и пропускала основную таблицу флеша Fudan, она лежит с 0x80): JEDEC-id, заголовок SFDP (32 байта) и 64 байта основной таблицы по указателю заголовка 0, внешней флеш, прочитанные командой `5A`. Патч загрузчика при сборке (`bootloader/patch_sfdp.py`) нужен из-за негодных значений в этой таблице; пришлите эти строки с каждого типа тега, чтобы проверить необходимость для каждого чипа
- `TR n t тип n=всего b=блоков: байты`: записи журнала, `t` — мс от первой записи. Типы: `C` команда (первый байт — команда), `D` данные (поток пикселей: первые байты, общая длина и число блоков), `X` чтение, `N` смена уровня RST (байт — уровни: бит 0 BUSY, бит 1 RST, бит 2 DC), `W` пауза в мс, `B`/`b` начало / конец ожидания BUSY, `A` питание включено, `Z` выводы отпущены (уровни до отпускания), `I` обмен с NFC по I2C (адрес, флаги, успех, длины, первые байты).
Буфер журнала 2 КБ, заполняется один раз; записи NFC могут занять только его начало.

## Цена
Диагностический образ требует на 2 КБ RAM больше и на несколько КБ больше flash. Если на теге не помещается, уменьшите `SL_HEAP_SIZE` только для этой сборки.
